# HudumaSim VR — Unity C# Starter Prototype

**Status:** Initial working-source prototype (not yet a production VR headset application).

## Requirements
- Unity Hub and **Unity 6 (6000.0.23f1 recommended)**. If unavailable, use a compatible Unity 6 editor and allow package resolution.
- Desktop PC/Mac for first testing.
- No API keys, downloaded assets, internet services or XR packages needed to run the initial demo (Unity may need internet to install packages).

## Quick start
1. Clone the repository and in Unity Hub select **Add project from disk**.
2. Choose the cloned repository root (the folder containing `Assets`, `Packages`, and `ProjectSettings`).
3. Open the project with Unity 6. Wait for the initial script compilation and package import.
4. Select **HudumaSim VR > Create Demo Scene** from Unity's menu. This creates `Assets/Scenes/HudumaDemo.unity` and adds it to Build Settings.
5. Press **Play** in the Unity Editor.
6. Click **Start Training**, choose a sector and scenario, select three replies, then inspect the assessment.
7. Click **Save assessment as JSON** to save results to `Application.persistentDataPath/sessions`.

**Alternative:** The runtime bootstrap automatically creates the app when any scene starts, so you can also press Play in an empty scene. The menu command creates a scene suitable for builds.

## Features in this milestone
- Simple generated 3D service counter and animated placeholder complainant
- Sector selection: Tax Ombudsman, Banking, Telecommunications
- Nine scenarios (three per sector)
- Three dialogue decisions per scenario and simulated emotional responses
- Deterministic scoring: listening 30%, calmness 30%, solution 40%
- Feedback, retry, and offline JSON session saving
- No external services; scenario content and assessment work offline

## Important limitations
- This is a **desktop, mouse-driven Unity prototype** using Unity's immediate-mode OnGUI. It is **not yet an immersive VR interface** and has not been tested on Quest or smartphone VR.
- The character is a placeholder assembled from primitive shapes, not a rigged avatar.
- Dialogue is choice-based, not speech recognition; emotions are rule-based, not generated by an AI model.
- The assessment is a prototype rubric, not validated for staff performance decisions.
- Session files are unencrypted local JSON; use synthetic training data only.
- There is no authentication, manager dashboard, database server, or admin content editor in this milestone.

## Suggested next milestones

## Code map
- `Assets/Scripts/HudumaModels.cs` — data models and weighted scoring
- `Assets/Scripts/ScenarioLibrary.cs` — nine scenario definitions
- `Assets/Scripts/TrainingSession.cs` — training state, emotion, assessment and JSON persistence
- `Assets/Scripts/HudumaApp.cs` — desktop UI and simple 3D environment
- `Assets/Editor/HudumaProjectSetup.cs` — one-click demo scene creation

## Troubleshooting
- If package resolution fails, use Unity's Package Manager to resolve/remove optional packages, or start with a new Unity 6 **3D Core** project and copy `Assets/Scripts` and `Assets/Editor` into it.
- If you see a blank Game view, open the generated scene and press Play.
- If controls are hard to read, maximize the Game view or choose a 1280×720 resolution.

## Research use
HudumaSim VR is an educational prototype. The case-study scenarios are illustrative and do not represent official Tax Ombudsman, bank, or telecom procedures. Validate complaint escalation workflows and compliance requirements with relevant institutions before deployment.
